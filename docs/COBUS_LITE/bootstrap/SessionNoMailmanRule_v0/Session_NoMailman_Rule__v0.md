# Session_NoMailman_Rule__v0

## Rule
Human mailman behavior is deprecated except magenta-emergency cases.

A lane must live or die based on:
1. bootstrap quality
2. pointer completeness
3. public/raw discoverability
4. self-mined handoff artifacts when needed
5. executable ACTION-last block discipline

## Bootstrap/Handoff Standard
- bootstrap from CoGoAll / CoBeacon / CoBus pointers
- prefer public/raw artifacts over prose
- handoff only by pointer-first compact artifacts
- no hidden local truth
- no dashboard authority

## Mandatory Wave Footer
Every wave must end with an ACTION section.
The ACTION section must be the last section.
The ACTION section must contain a CLI-copyable block suitable for CoPing / CoGuardian / CoGuard / CoStacks execution.

## Invalid Wave Conditions
A wave is invalid if it lacks any of:
- concrete mutation artifact
- executable DO/ACTION block
- proof receipt
- explicit blocked-state declaration

## CoPulse Rule
Each valid wave emits at least one CoPulse:
- public/raw artifact
- SHA-backed receipt
- verified pointer delta
- compact public SideNote/CoPong with state change
- execution receipt

## Truth Precedence
1. RAW + SHA
2. RAW
3. payload body
4. lane narration

## Default Direction
- no more mailman
- no more prose-only orchestration waves
- no more ACTION-missing waves
- sessions are lanes
- lanes are disposable
- verified public artifacts are authoritative
