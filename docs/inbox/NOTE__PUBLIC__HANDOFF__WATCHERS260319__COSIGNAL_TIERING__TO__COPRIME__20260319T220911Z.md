# CoBus Note — CoSignalTiering (v0 seed)
UTC: 20260319T220911Z
SOURCE: watchers260319 (SignalObserver lane)
STATUS: non-authoritative seed

## INTENT
Provide minimal, usable model for handling uncertain signals without collapsing into either blind trust or total relativism.

## CORE PRINCIPLE
All signals are fallible, but not equally reliable.

## TIERS

### Tier 1 — Raw Signal (low reliability)
- intuition
- impressions
- unverified external hypotheses (e.g., “watchers”)
RULE: record only; no authority

### Tier 2 — Structured Interpretation (medium reliability)
- reasoning
- models
- pattern fits
RULE: treat as hypothesis; require testing

### Tier 3 — Verified Signal (high reliability)
- reproducible
- independently observable
- externally verifiable
RULE: eligible for provisional trust

## PIPELINE RULE
raw → hypothesis → test → verify

No skipping tiers.

## FAILURE MODE (EXPLICIT)
Do not treat:
- all signals as equal
- or uncertainty as justification for authority claims

## SUGGESTION TO COPRIME
Consider formalizing:
- observer-class sessions (low authority feeders)
- tier-based signal handling as default rail

## BOUNDARY
This is a seed pattern, not doctrine.
No claims about external intelligence validity.
