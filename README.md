## Evidence boundaries

A published file demonstrates repository availability, not independent backup custody. Recovery readiness requires an independently held copy, exact-object readback, and a successful restore rehearsal.

Private material, credentials, and unclassified artifacts are excluded from public mirroring.

**Status:** Public source repository. Independent survivability and recovery acceptance are not established by this README.
